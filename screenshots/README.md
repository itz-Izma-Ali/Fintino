# Screenshots

Drop PNG screenshots into this folder using the filenames below. They are
referenced from the main `README.md`.

| File | What to capture | Recommended size |
|---|---|---|
| `01-onboarding.png` | Onboarding step 1 (the stacked-cards hero) | 1080×1920 |
| `02-signin.png` | Sign-in screen | 1080×1920 |
| `03-home-dark.png` | Home tab in dark mode | 1080×1920 |
| `04-home-light.png` | Home tab in light mode | 1080×1920 |
| `05-wallet.png` | Wallet tab — front card visible | 1080×1920 |
| `06-wallet-swipe.png` | Wallet tab — mid-swipe | 1080×1920 |
| `07-stats.png` | Stats tab — bar chart + donut | 1080×1920 |
| `08-profile.png` | Profile tab | 1080×1920 |
| `09-send.png` | Send money screen | 1080×1920 |
| `10-receipt.png` | Receipt screen | 1080×1920 |
| `11-txn-detail.png` | Transaction detail | 1080×1920 |
| `12-notifs.png` | Notifications screen | 1080×1920 |

How to capture on a running emulator:

```bash
# From the Flutter run, press "s" in the terminal — saves to ./screenshots/
# Or use the CLI:
flutter screenshot --out=screenshots/03-home-dark.png
```
